# 🧠 **ApplyRight – An AI-Driven Resume Optimizing Tool**

**Duration:** February 2025 – May 2025  
**Tech Stack:** FastAPI · React (TypeScript) · Supabase · OpenAI API · Gemini API  

---

## 🚀 **Overview**

**ApplyRight** is an AI-powered resume optimization platform designed to help job seekers tailor their resumes to specific job descriptions.  
The system leverages **LLMs (Gemini + OpenAI APIs)**, **prompt-engineered skill extraction**, and a **Retrieval-Augmented Generation (RAG)** pipeline to deliver precise and personalized resume recommendations.

The platform intelligently analyzes a user’s resume and the target job posting, performing **structured metadata parsing**, **skill gap analysis**, and **tone-preserving rewriting** to maximize alignment.

> Achieved **85%+ match accuracy** between optimized resumes and target job descriptions.

---

## 🧩 **Features**

### 🔍 **AI-Powered Resume Analysis**
Extracts key skills, experience, and tone using prompt-engineered pipelines for accurate semantic understanding.

### 🧠 **RAG-Powered Matching Engine**
Uses **Supabase vector search** to retrieve relevant job-specific context, improving model recall and alignment.

### ⚙️ **Metadata Parsing & Scoring**
Custom extractor built to identify structured metadata (skills, experience levels, metrics) and assign weighted scores.

### 💬 **Tone Preservation & Enhancement**
Maintains the user’s original voice and phrasing while improving clarity, conciseness, and professional tone.

### 🌐 **Full-Stack Implementation**
- **Backend:** FastAPI serving multi-model prompt chaining and scoring endpoints  
- **Frontend:** React (TypeScript) UI for interactive job upload, resume input, and live optimization feedback  
- **Database:** Supabase (vector embeddings + structured storage)
